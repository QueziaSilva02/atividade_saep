Aplicação web desenvolvida para a avaliação **SAEP**, utilizando **PHP** e **MySQL** para realizar a gestão completa de eleitores e candidatos através de operações CRUD e metodologia ágil **SCRUM**.

---

## 📘 Sobre o Projeto

O objetivo desta atividade é aplicar na prática os conceitos de modelagem e manipulação de Banco de Dados relacional integrados ao backend em PHP. A aplicação gerencia registros eleitorais permitindo operações de criação, leitura, edição e exclusão de dados.

### 🔷 Funcionalidades
**Cadastrar:** Registro de novos eleitores e candidatos.
**Consultar:** Visualização e listagem dos dados armazenados.
**Atualizar:** Edição de dados previamente cadastrados.
**Excluir:** Remoção de registros do sistema.

---

## 🗄️ Estrutura do Banco de Dados

**Database:** eleitor
**Tabelas:**
  * eleitor — Guarda as informações dos eleitores cadastrados.
  * candidato — Guarda os dados das candidaturas ativas.
